# 校园墙官网内容知识库

> AI 助手仅依据本文件内容回答"官网/平台"类问题。内容可直接编辑替换为学校官网真实内容。

## 平台简介

校园墙（Campus Wall）是面向本校学生的校园信息聚合社区平台，按场景分类提供二手交易、失物招领、表白墙、吐槽树洞、互助问答、校园活动等垂直板块，解决校园信息碎片化、传播效率低、匿名表达需求强等痛点。

## 六大板块

| 板块 | 说明 |
|---|---|
| 二手交易 | 发布/求购二手物品，支持价格、新旧程度、联系方式等字段 |
| 失物招领 | 捡到物品或寻找失物，支持地点、时间、物品描述字段 |
| 表白墙 | 匿名/实名表白、交友互动 |
| 吐槽树洞 | 强制匿名板块，可放心倾诉 |
| 互助问答 | 学习、生活问题互助解答 |
| 校园活动 | 讲座、社团、比赛等活动信息，支持时间、地点、主办方字段 |

## 发帖规则

1. 使用学号注册登录后即可发帖，发帖前内容会经过敏感词检测：高风险词直接驳回，中风险词进入人工审核队列。
2. 部分板块需要审核（need_audit），审核通过后帖子才会公开显示。
3. 每个帖子有每日发布上限频控；评论有 10 秒频控；举报有 24 小时频控。
4. 帖子发布后 24 小时内可以编辑；删除为软删除，后台可追溯。

## 匿名规则

- 树洞板块强制匿名。
- 信誉分 ≥ 90 的用户可在其他板块选择匿名发布。
- 匿名发布后台可溯源，用于违规处理，普通用户不可见。

## 信誉分体系（0-120 分）

| 分值区间 | 功能权限 |
|---|---|
| 90-120 分 | 全部功能正常，支持匿名发布 |
| 80-89 分 | 正常发帖评论，不可匿名 |
| 60-79 分 | 每日限发 3 条，不可匿名，不可发二手交易 |
| 0-59 分 | 禁止发帖评论，仅可浏览 |

## 举报与安全

- 发现违规内容可举报，24 小时内限一次；同一内容被 3 人举报会提升处理优先级。
- 管理员处理举报的方式包括：驳回举报、删除内容、封禁账号。

## 常见问题

**Q：怎么发帖？**
登录后点击底部"+"按钮，选择板块、填写标题和内容即可发布；可存草稿自动保存。

**Q：怎么联系卖家/失主？**
二手交易和失物招领帖子会在详情页展示联系方式或额外字段信息。

**Q：帖子为什么没显示？**
可能处于待审核状态（部分板块需要审核），或被敏感词检测拦截进入人工审核。

**Q：怎么找回密码？**
请联系管理员在后台重置密码。
