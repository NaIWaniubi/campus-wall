# 校园墙小红书内容流 + Apple 质感 UI 改版设计

## 目标

把当前“模板感较强、排版偏硬”的校园墙，改成更像正式内容社区的小程序：内容卡片更吸引人，整体更干净、更柔和，同时保留校园墙自己的青绿色品牌识别，不照搬小红书红色。

## 视觉关键词

- 小红书式内容卡片：大圆角、轻阴影、作者信息清晰、正文和图片优先。
- Apple 式界面质感：浅灰页面背景、克制色彩、通透留白、自然微动效。
- 校园社区气质：绿色主色保留，降低渐变强度，让界面更清爽可信。

## 第一轮改版范围

1. 全局视觉系统
   - 统一背景为柔和浅灰。
   - 统一卡片圆角、阴影、字体层级、按钮按压反馈。
   - 减少重渐变和过强装饰。

2. 首页内容流
   - 弱化当前大面积渐变头部，改成轻量搜索栏 + 横向频道胶囊。
   - 帖子列表改为更强的内容卡片流。
   - 卡片之间增加呼吸感，减少拥挤。

3. 帖子卡片组件
   - 作者区：头像、昵称、时间、校区信息更精致。
   - 正文区：字号、行高、截断更适合阅读。
   - 图片区：单图大图、多图网格，统一圆角和间距。
   - 互动区：点赞、评论、收藏改成轻按钮风格。

4. 详情页
   - 延续首页卡片语言。
   - 阅读区和评论区分层更明确。
   - 底部评论栏改成 iOS 式悬浮输入条。

5. 发布页
   - 表单改成 iOS 风格分组卡片。
   - 输入框、图片上传、匿名/私信开关更整洁。
   - 发布按钮更稳重，保留明确主操作。

## 动效规范

- 页面进入：轻微淡入 + 上移，不做夸张弹跳。
- 卡片出现：短时延迟的淡入上移，增强内容流质感。
- 按钮点击：轻微缩放和透明度反馈，接近 iOS 按压感。
- 悬浮发布按钮：不做持续跳动，改为静态高级阴影 + 点击反馈。
- 动效时长：主要控制在 180ms–360ms，避免拖沓。

## 不做的事

- 不改后端数据结构。
- 不引入付费服务。
- 不大幅重构业务逻辑。
- 不照搬小红书品牌红色。
- 不做复杂瀑布流算法，第一轮先把现有列表卡片做到好看、稳定。

## 验收标准

- 微信开发者工具能正常编译。
- 首页第一屏明显更像内容社区，不再像通用模板。
- 首页、详情、发布页视觉语言统一。
- 按钮点击、卡片加载有自然反馈。
- 原有点赞、收藏、评论、发布、跳转功能不被破坏。
