# 校园墙 · 作品速贴版（表单/答辩开场用，约 1100 字）

## 作品名称
校园墙 —— 面向高校的 AI 原生校园社区（Web + 微信小程序双端）

## 一句话介绍
把 AI 放进校园社区的**发布、阅读、浏览三条主路径**而非角落聊天框：一句话成稿、一键划重点、个性化每日简报，并在发布后主动防重复刷屏、读完后继续推荐相关内容——每个 AI 能力都有确定性规则兜底，模型挂了功能不挂。

## 解决什么问题
校园墙类产品长期停在「信息流堆卡片 + 角落客服 AI」。学生真正的高频痛点是三个动作太慢：发一条帖子要填 6 个字段、读长帖要自己找重点、每天想知道「学校今天发生了什么」。校园墙把 AI 做成这三个动作的默认路径，同时保留传统交互作为兜底。

## 三个记忆点（评委三分钟内可验证）

| 记忆点 | 验证方式 |
|---|---|
| **失物智能雷达**：发「捡到校园卡」自动匹配方向相反的求助帖 | 离线评测 P@1 100%、MRR 1.000（纯关键词基线 19%），误报率 7.1%（刻意用召回换精确），`npm run eval:radar -- --gate` 进 CI 回归门 |
| **匿名是真的匿名** | 匿名帖不可按作者反查、编辑不脱匿名、列表缓存按可见性分维度、封禁后旧 token 立即失效（REST/WS 双通道），四路反查有回归测试 |
| **治理闭环** | 发布→机审+词表→人工队列→举报→处理→审计留痕，后台数据总览可见待审/举报/通过率/7 日趋势 |

## AI 技术深度（四子系统，全部有降级路径）

1. **RAG 检索增强**：文档按标题切块 + 内容哈希增量索引；嵌入双路径（网关优先 / 本地 1024 维中文 2-gram 哈希嵌入兜底 + 受控同义词归一）；向量+关键词混合排序，回答带引用溯源。
2. **Agent 工作流**：LLM 规划 → 工具调用（搜帖/失物匹配/统计/知识库）→ SSE 逐步事件流 → 前端时间线可视化；规划失败自动回落规则规划，全程不黑箱。
3. **AI 护栏**：中英双语注入模式库分级（高危直接拒答且不调模型、中危剥离续聊）；输出侧风险改写 +「引用编号必须来自检索命中集」的幻觉红线；29 条评估样本一键复现（29/29，0.5ms/条）。
4. **多模态**：发帖图片理解（视觉网关 → 启发式兜底：尺寸/主色调/明暗），元数据落库供标签聚合；双重失败返回安全占位，不阻塞发布。

**本轮 AI 深度扩展**：发布时相似帖检测（9 组标注标定阈值，真重复最低 0.816 / 非重复最高 0.040，命中仅提醒不拦截）；详情页相关推荐（高文本相似优先 + 同板块兜底，排除自身/待审/删除/封禁作者）；登录用户个性化日报（订阅板块 + 近期互动，用户级 60s 缓存，模板优先、LLM 后台润色）。

**「耐用」的工程定义**：整条模型链带总预算 + 单模型超时 + 5 分钟熔断。实测网关失效时首次 15s 内返回规则版，熔断期内 4 次调用合计 <1s、0 网络请求。

## 工程质量（可复现数字）

- 后端 Express 5 + SQLite（FTS5 中文二元分词）+ WebSocket 私信；前端 Vue3 + TS + Pinia + Vite
- **500 条自动化测试**（61 文件）、**17 条 Playwright E2E**（真 Chromium 全流程，含路由复用回归的负向对照）、RAG 50 条分层评测 recall@5=0.988 且防幻觉负例零违规、相似帖阈值评估门通过、lint/typecheck 0 错误
- **CI 五个 job 常绿**：静态 verify → Docker 镜像构建与容器冒烟 → 浏览器 E2E → Lighthouse → 契约压测（24 并发零 5xx、~2409 req/s、p95 5ms）
- 安全：双 token（access 2h 仅内存 + refresh 7d 单次消费/重放即拒）、401 双入口静默续期、微信 msgSecCheck 文本机审 + 图片异步送审、匿名四路反查防护、上传防解压炸弹
- 部署：单进程 `bash start.sh` 即起；空目录冷启动自动建库灌种子；已在 Ubuntu 24.04 + Node 24 复验全链路 0 个 5xx

## 双端与合规
Web（Vue3）+ 原生小程序（34 页）共用同一后端契约；用户协议/隐私政策双端同源生成、注册强制勾选；小程序端接微信内容安全接口（未配凭据自动降级为本地词表）。
