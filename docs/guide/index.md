# 项目概览

校园墙（Campus Wall）是面向本校学生的**校园信息聚合社区平台**，按场景分类提供八大垂直板块，支持 **Web 网页端 + 微信小程序**双端访问。

## 解决的痛点

- 校园信息碎片化：公告散落在多个群聊，检索困难
- 传播效率低：一条失物招领很难触达需要的人
- 匿名表达需求强：树洞、表白等场景需要合规的匿名能力

## 功能板块

| 板块 | 关键能力 |
| --- | --- |
| 二手交易 | 差异化字段（价格/新旧/联系）、标记已售、买卖双方互评 |
| 失物招领 | 关键词打分自动匹配站内相似物品，双向通知 |
| 表白墙 / 树洞 | 强制匿名板块，后台可溯源 |
| 互助问答 | 楼中楼回复、最佳回答 |
| 校园活动 | 时间/地点/主办方字段 |
| 拼车 / 组队 | 位置与联系信息 |

## 账号与信誉体系

- 学号注册登录，个人中心完整资料
- 信誉分 0–120 分级权限，违规扣分、互评联动升降
- 匿名发布后台可溯源，信誉分阈值控制发帖权限

## 技术栈一览

| 层 | 技术 |
| --- | --- |
| Web 前端 | Vue 3 + Vite + TypeScript + Tailwind CSS + Pinia |
| 小程序 | 原生小程序（WXML/WXSS/JS） |
| 后端 | Node.js + Express + TypeScript |
| 数据 | SQLite（better-sqlite3）+ 迁移脚本 |
| 实时 | WebSocket（会话/通知） |
| 测试 | Vitest（单元）+ Playwright（E2E）+ 小程序静态断言 |
| 文档 | VitePress（本站） |
