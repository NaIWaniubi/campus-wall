# 90 秒演示视频分镜（录屏脚本）

> 目标：让评委在 90 秒内看完「AI 进主链路 + 失物雷达 + 治理闭环」三件事。
> 录制建议：1440×900 桌面为主，穿插 390×844 手机（可用浏览器设备模拟）。
> 旁白语速按 4 字/秒控制，每镜头字幕与旁白一致。

## 时间轴

| 时间 | 画面 | 操作 | 字幕/旁白 |
|---|---|---|---|
| 0:00–0:08 | 首页首屏（桌面） | 打开站点，停在「今日校园」简报卡 | 「校园墙：AI 原生的校园社区。首页第一块就是今日简报。」 |
| 0:08–0:20 | 首页简报 → 失物招领板块 | 点简报里的「失物招领」，进入板块：帖子里有「捡到校园卡」 | 「八板块里最能说明问题的是失物招领。」 |
| 0:20–0:35 | 帖子详情：雷达匹配 | 打开「捡到一张校园卡」，滚动到「可能相关」区块 | 「发帖瞬间，系统自动匹配出方向相反的求助帖——离线评测 P@1 100%，而纯关键词只有 19%。」 |
| 0:35–0:45 | 详情页 AI 划重点 | 点「AI 划重点」按钮，展示 3 条要点 + 风险提示 | 「长帖一键划重点。规则抽取兜底，断网也有结果。」 |
| 0:45–1:00 | 发布页 AI 成稿 | 点「发布」→ 在 AI 卡输入「出九成新 iPad Air，1500 元，可小刀，东门当面」→ 点「AI 成稿」→ 标题/正文/板块/价格/标签一次填好 | 「一句话成稿：标题、正文、板块、价格、标签全部自动补全。模型不可用时走规则版，同样可用。」 |
| 1:00–1:10 | 评论/私信实时 | 在详情页发一条评论，切到消息页看到通知（WebSocket） | 「评论与私信走 WebSocket 实时链路，REST 永远兜底。」 |
| 1:10–1:20 | 后台治理 | 打开 `/admin`：待审队列、举报、审核通过率 | 「治理闭环：机审 + 人工队列 + 举报处理 + 审计留痕，全部可追溯。」 |
| 1:20–1:30 | 安全与工程收尾 | 切到 GitHub Actions 页面（CI 六道门全绿）→ 回首页 | 「407 条测试、15 条 E2E、CI 六道门全绿。工程可信度，是能被验证的。」 |

## 录制前检查单

1. 起生产包（更接近线上）：`bash .zcode-site/stage/start.sh`，或 `npm run dev`
2. 演示库种子已灌：`npm run seed`（首启自动）
3. 浏览器缩放 100%，隐藏书签栏；录屏 1080p/60fps
4. 关闭无关通知；路由进度条与 toast 保留（体现产品完成度）
5. 若 AI 网关不可用：**不要念「AI 失败」**，直接说「走规则兜底」——这是设计的一部分

## 可用素材

- 桌面/手机静帧：`captures/v5/`（21 张）、`captures/v6/`（法律页/注册协议 4 张）
- 复现脚本：`node scripts/capture-v5.mjs`（起 dev server 后）
- 若时间不够只录 45 秒：0:00–0:08 + 0:20–0:35 + 0:45–1:00 三段即可覆盖全部评分点
