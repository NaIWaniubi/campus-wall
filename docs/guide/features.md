# 功能全景（V5）

校园墙按场景分八大板块：**二手交易 / 失物招领 / 表白墙 / 吐槽树洞 / 互助问答 / 校园活动 / 拼车 / 组队**。
Web（Vue 3 + TS）与微信小程序（原生，29 页）共用同一套 REST + WebSocket 后端契约。

## 进场与浏览

- **零门槛登录**：通用账号（手机号/拼音/邮箱前缀）+「一键体验（免输入）」+「游客逛逛」；字段级内联错误
- **全局命令面板** `Ctrl/⌘+K`：实时搜帖 + 板块直达 + 页面跳转 + 最近搜索
- **新手三步引导**：首访自动弹（选板块/发布/AI），会话内不重弹，设置页可重看
- **信息流**：热门/最新排序、板块 Tab、信誉徽章、置顶；三处列表虚拟滚动（首页/板块/搜索）
- **搜索**：FTS5 中文二元分词全文检索，300ms 防抖 + 本地历史 + 热门词

## 发布与互动

- 发帖：剪贴板粘贴 + 拖拽传图、发布前所见即所得预览、敏感词分级（硬词转人工审核）
- 云草稿：跨设备 10 条上限自动轮换；24h 内可编辑
- 互动：点赞/收藏/楼中楼回复/热门评论标识/举报（24h 频控、3 人升优先级）
- 评论通知直达：点通知滚到具体楼层并柠色闪烁 2.6s
- 分享海报：详情页一键生成 750×1000@2 纯 canvas 海报（下载/复制/系统分享）

## 失物智能雷达

发「捡到校园卡」自动匹配方向相反、品类一致的求助帖。
离线评测：P@1 **100%** vs 纯关键词基线 19%，MRR 1.000，误报 7.1%（刻意取舍：漏报代价高于误报）。
`npm run eval:radar -- --gate` 进 CI，指标跌破阈值即红。详见 [质量门](/guide/testing)。

## 治理与信誉

- 信誉分 0–120 分级权限；信誉之星徽章
- 发布→审核→举报→处理→审计留痕全闭环，后台 11 页 V4 全量重构
- 匿名四道锁见 [安全与匿名](/guide/security)

## 触达与传播

| 通道 | 形态 | 兜底 |
|---|---|---|
| WebSocket 实时 | 任意页面未读徽标 + toast 摘要 | 离线 REST 拉取 |
| Web Push | 设置页一键开启，离线系统通知点击直达 | VAPID 未配置入口自动隐藏 |
| 微信订阅消息 | 发帖/评论 tap 链内授权，评论/匹配离线触达 | 模板未配置静默跳过 |
| OG 分享卡片 | `/post/:id` 服务端注入，微信/QQ 裸链出图 | 仅 published，审核中不外露 |
| JSON-LD / sitemap / RSS | 搜索引擎富摘要 + 订阅器自动发现 | 匿名归一「匿名同学」 |
| 小程序分享卡 | 服务端 sharp 合成 750×600 V4 纸感卡 | 有图帖用首图（绝对化） |
