# AI 架构：主链路 + 三层兜底

AI 不是角落聊天框，而是三条主路径上的明确产出：

| 入口 | 产出 | 离线兜底 |
|---|---|---|
| 发布页 · 一句话成稿 | 标题/正文/板块/价格/标签 | 板块套版：抽取原文实有的物品/成色/价格/时间/地点/联系方式成 📌 清单；情绪板块不套版 |
| 详情页 · AI 划重点 | 3 条要点 + 交易风险提示 | 抽取式摘要（标题滑窗 + 句长 + 位置权重）；风险词规则始终生效 |
| 首页 · 今日校园简报 | 统计 + 最活跃板块 + 最热 + 安全提醒 | SQL 统计 + 模板句，60s 缓存，永不空窗 |

## 模型路由与分轨

- `routeFor`：`:free` 后缀模型走 OpenRouter 官方 + `OPENROUTER_API_KEY`；其余走自建网关 `AI_BASE_URL` + `AI_API_KEY`
- **前台/后台分轨**：当面等的成稿/划重点/助手只走快网关链（`fastOnly` 剔除慢免费档）；慢但免费的真模型专职后台简报（100s 大预算 + `ignoreBreaker`，成功即复位熔断为前台探活）
- **网关级 auth 短路**：自建网关 401/Invalid token 时，同端点（url + key 尾 6 位指纹）其余模型不再逐个空耗，直接切免费档

## 耐用性三件套

1. **预算**：总预算 `budgetMs` + 单模型 `perModelTimeoutMs`，超时即落兜底
2. **熔断**：失败 trip 5 分钟，熔断期内 0 网络直返规则版；后台简报成功即 reset
3. **离线套版**：无 key/熔断/全挂时仍产出规范稿——实测失物招领一句话 →「【失物招领】校园卡」+ 干净标签

## 免费档 reasoning 模型的坑与解

OpenRouter 免费 reasoning 模型在严格 JSON 提示词下会把 token 烧进思考导致 `content` 空：
预算提到 4096 + `reasoning.effort=low` + `salvageJsonFromReasoning` 从思考尾部打捞 JSON。
实测今日简报 60s 后 `offline:false` 真实出稿。

## 站内检索兜底

在线模型全挂/未配置时，AI 助手用知识库 + 论坛检索作答：不编造、不失联。
